# Tripadvisor Clone

A simple **Tripadvisor website clone** created using **HTML and CSS**.  
This project is built for practicing webpage structure, styling, layouts, and responsive design.

## 🚀 Features

- Responsive navigation bar
- Tripadvisor-style homepage
- Search section
- Travel destination sections
- Restaurant and hotel sections
- Image cards
- Hover effects
- Responsive layout for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```text
Tripadvisor-Clone/
│
├── index.html
├── style.css
└── images/
    └── images used in the project
```

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
